# 信息流与隐私边界

本 Skill 有两条入口，不能将它们的保密承诺混为一谈。

| 入口 | 模型接触什么 | 本地程序接触什么 |
|---|---|---|
| 独立本地填写 | 打开状态、一般操作说明 | 用户在页面填写的字段及生成的 Word |
| 模型辅助生成 | 用户提供或明确指定的材料、提取参数，以及授权模型读取的成品 | 参数 JSON、内置模板、生成文件与核验记录 |

`open_local.py` 不读取输入文件，也不提供截图、表单读取或下载扫描功能。HTML 无第三方远程脚本、字体、统计或案件上传接口；页面 CSP 禁止连接外部服务。`generate.mjs` 使用独立临时浏览器上下文，拦截 HTTP/HTTPS 请求、禁用 service worker，不记录截图、视频或追踪，不把浏览器日志传给模型。

这些措施约束的是本工具的数据流，不限制另一个进程、云端同步、浏览器扩展或拥有文件读取权限的模型。不得宣称它构成零泄露、匿名化、客户机隔离或服务商零留存。需要严格隔离时，使用独立离线入口并由宿主禁止模型读取真实目录；当前客户端不能做到时应明确这一实际限制。

真实输入、原文件、参数、成品和核验报告应放在用户选定的本地案件目录。用户要求“资料仅保存在本机”时，避开 iCloud、OneDrive、Dropbox 等自动同步目录；不要静默移动或删除用户原文件。本次 Skill 的代码位于同步目录不意味着未来案件也应保存在那里。

代码运行时不打印客户名称、证件号、联系方式、地址、案件路径或文书原文。CLI 的中性文件名为 `client-001-authorization.docx` 等；真实名称仍在 Word 正文和本地 `source-plan.json` 中。下载页面沿用原工具的可读文件名，文件名也可能包含真实名称，仅由用户在本地查看和保存。

模型辅助过程中用户已发来的原文仍属于模型输入；本地计算、生成、后续替换姓名均不能逆转这一事实。精确日期、特殊交易及金额组合可能识别案件，单纯换名并不能证明不可复原。

共享代码包或 GitHub 仓库不附带实际案件目录。本次仓库按用户的发布指示保留现有内置汉坤 Word 模板、分所资料和收款账户配置；后续更新或分享不得顺带加入客户材料、实际参数或成品，也不得据此推定其他资源可以公开。公开仓库不构成事务所模板的通用开源许可。Git 忽略文件不是访问控制，也不能清除已经进入 Git 历史的数据。
